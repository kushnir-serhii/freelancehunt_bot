# freelancehunt_bot

Слідкує за новими проєктами на Freelancehunt і кидає релевантні в Telegram.
Один кодовий базис: локальний запуск і Cloudflare Worker — той самий файл.

## Що робить

Раз на хвилину тягне `GET /v2/projects`, порівнює з останнім побаченим id,
фільтрує нові за ключовими словами й бюджетом, шле в Telegram.
На першому запуску нічого не розсилає — лише ставить точку відліку.

## Запуск локально

1. `npm install`
2. `cp .dev.vars.example .dev.vars` і заповни три токени
3. `npm run dev`
4. В іншому терміналі: `curl "http://localhost:8787/run?key=dev"`

Локально KV працює у файлі всередині `.wrangler/` — нічого налаштовувати не треба.

### Роути (усі, крім `/health`, вимагають `?key=`)

| Роут      | Що робить                                                   |
| --------- | ----------------------------------------------------------- |
| `/run`    | Разовий прогін вручну, повертає скільки знайшов і надіслав   |
| `/debug`  | Сирий JSON першого проєкту — звірити назви полів             |
| `/reset`  | Забути стан, наступний запуск почне відлік заново            |
| `/health` | Пінг                                                         |

## Деплой

```bash
npx wrangler kv namespace create STATE     # id -> у wrangler.toml
npx wrangler secret put FH_TOKEN
npx wrangler secret put TG_TOKEN
npx wrangler secret put TG_CHAT_ID
npx wrangler deploy
```

Логи в реальному часі: `npm run tail`.

## Налаштування фільтрів

Усе вгорі `src/worker.js`, блок `CONFIG`:

- `stems` — основи слів без закінчень (`верстк` ловить «верстка», «верстку»)
- `exclude` — стоп-слова, відкидають проєкт навіть при збігу
- `minBudgetUAH` — 0 = без обмеження
- `includeNoBudget` — чи пускати проєкти без бюджету
- `maxPerRun` — стеля повідомлень за прогін

## Ліміти

Cloudflare free: 100 000 запитів/добу, cron від 1 хвилини, 1000 записів KV/добу.
1440 запусків на добу — близько 1,5% квоти. Запис у KV лише коли є нові проєкти.

Вузьке місце — rate limit самого Freelancehunt API. Дивись `X-Ratelimit-Remaining`
у відповіді `/run`; якщо близько до нуля, постав крон `*/2 * * * *`.

## Відомий ризик

Документація Freelancehunt не описує повну структуру об'єкта проєкту.
`normalize()` читає поля і з кореня, і з `attributes`. Якщо повідомлення
приходять порожні — глянь `/debug` і поправ `normalize()` під реальні назви полів.
